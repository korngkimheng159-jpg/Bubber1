# ធ្វើឱ្យអ្នកដទៃបើកប្រើបាន (Public mode)

គោលការណ៍: **server** រត់លើ Internet (VPS) ហើយមនុស្សគ្រប់គ្នាបើក **ទំព័រវេប/ app** តភ្ជាប់ទៅវា។ ម្នាក់ៗមាន token ផ្ទាល់ខ្លួន។

## 1) ដាក់ server លើ VPS (មើល DEPLOY.md)
`docker compose up -d --build` ជាមួយ `.env` ដូចខាងក្រោម។ ត្រូវមាន domain + HTTPS (Caddy ក្នុង docker-compose.yml) ដើម្បីឱ្យ app/PWA ដំឡើងបាន។

```
# .env
KD_TOKEN=ពាក្យសម្ងាត់-admin-វែងៗ          # របស់អ្នក (admin)
KD_TOKENS=anna:tok-anna-123,bob:tok-bob-456  # មិត្តភក្តិម្នាក់ម្ន token (លុបចេញ = ដកសិទ្ធិ)
KD_MAX_MB=500        # វីដេអូធំបំផុត
KD_MAX_MIN=20        # វែងបំផុត (នាទី)
KD_MAX_JOBS=1        # ការងារធ្ងន់ព្រមគ្នា (ដែលនៅសល់ឈរក្នុងជួរ)
KD_PER_USER=2        # ការងារដំណើរការព្រមគ្នាក្នុងម្នាក់
KD_SHARE_KEY=0       # 0 = មិត្តភក្តិត្រូវដាក់ Gemini key ខ្លួនឯង (មិនស៊ី quota អ្នក)
```
បន្ទាប់ពីកែ `.env`: `docker compose up -d`

## 2) ផ្ញើឱ្យមិត្តភក្តិ
- តំណ `https://your-domain` + token ម្នាក់ៗ។
- ទំព័រវេប: ⚙ → ដាក់ Token (+ Gemini key ផ្ទាល់ខ្លួនបើមាន)។ ដំឡើងជា app: Android ប៊ូតុង "⬇ App", iPhone: Share → Add to Home Screen។
- APK: មើល BUILD_APP.md — ដាក់ URL + token ក្នុង ⚙ Settings។

## ការការពារដែលមាន
- ម្នាក់ឃើញតែការងាររបស់ខ្លួន (admin ឃើញទាំងអស់)។ ឯកសារលុបស្វ័យប្រវត្តិក្រោយ 24 ម៉ោង។
- កំណត់ទំហំ/រយៈពេលវីដេអូ, ជួររង់ចាំ, ដែនកំណត់ការងារក្នុងម្នាក់។
- Gemini key របស់ server មិនត្រូវបានប្រើដោយមិត្តភក្តិ លុះត្រាតែ `KD_SHARE_KEY=1`។

## ត្រូវដឹង (សំខាន់)
- **កម្លាំង server:** ការងារស៊ី CPU/RAM ខ្លាំង (Whisper, FFmpeg)។ VPS តូច + អ្នកប្រើច្រើន = យឺត។ ណែនាំ STT = Gemini។ ចាប់ផ្តើម `KD_MAX_JOBS=1`។
- **សំឡេង Edge TTS** ជា API មិនផ្លូវការ អាចត្រូវបានរារាំង IP របស់ VPS ឬបិទដោយគ្មានការជូនដំណឹង ហើយមិនសមស្របសម្រាប់សេវាពាណិជ្ជកម្ម។ ចង់ធ្វើជាផលិតផលពិត ត្រូវប្រើសេវា TTS ផ្លូវការ (ឧ. Azure Speech) ដែលមានតម្លៃ។
- **ទំនួលខុសត្រូវ:** អ្នកដទៃ Upload វីដេអូមកអ្នក (រក្សាសិទ្ធិ, ឯកជនភាព)។ ប្រាប់ពួកគេថាឯកសារលុបក្រោយ 24 ម៉ោង ហើយប្រើក្នុងចំណោមមិត្តភក្តិ/ក្រុមដែលទុកចិត្តបាន។
- ថ្លៃ និងគម្រោងឥតគិតថ្លៃរបស់ VPS ផ្លាស់ប្តូរ សូមពិនិត្យនៅអ្នកផ្តល់សេវាមុនជ្រើស។
